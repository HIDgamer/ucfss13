Vars

admin_bypass_ceremonyTRUE only while admin_fly_shuttle() (an admin/event debug tool) is choosing/executing a destination for this ship - lets canDock() skip the hangar airlock's outer-then-raise ceremony requirement for admin-forced moves without weakening it for normal player flights.

Procs

admin_fly_shuttleAdmin/event debug tool - allowed to bypass the hangar airlock ceremony outright, since it's meant to override normal flight rules for testing/event/stuck-round recovery, and on_departure()/ on_arrival()'s resync (see dropship_airlock.dm) already guarantees the airlock ends up in a physically consistent state regardless of how the ship got there.
canDockEvery path that can move a dropship (a player's flight console, admin "Fly Shuttle") funnels through here, so this is the one place that can require "must have come up through the hangar airlock's outer dock and raised" for a return trip without needing separate checks in each caller. See /obj/docking_port/stationary/marine_dropship/airlock/inner/proc/ceremony_satisfied_for().
