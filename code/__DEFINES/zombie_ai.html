#define

Default scan radius (tiles) used for target acquisition.

#define
ZOMBIE_AI_DEFAULT_HEARTBEAT

Ticks slept between ai_loop() iterations while actively engaged with a target - as low as sleep() grants, matching the xeno pattern (actual pacing is already gated for free by the pilot's own movement_delay()/attack cooldown).

#define
ZOMBIE_AI_DEFAULT_IDLE_HEARTBEAT

Ticks slept between ai_loop() iterations while idle/no target - cheaper than the engaged heartbeat, matching the xeno pattern (see AI_XENO_DEFAULT_IDLE_HEARTBEAT's doc comment for why this matters at scale: server load from the idle AI population scales roughly linearly with how low this is).

#define
ZOMBIE_AI_DEFAULT_RETURN_DISTANCE

Default leash radius (tiles) from anchor_turf before an AI zombie disengages and returns.

#define
ZOMBIE_AI_FALLBACK_WALK_DURATION

How long navigate_around() commits to a winning sidestep direction before re-evaluating - mirrors AI_XENO_FALLBACK_WALK_DURATION. Re-aiming fresh every tick instead reads as "walking back and forth" against anything wider than a single tile.

#define
ZOMBIE_AI_MELEE_ATTACK_DELAY

Minimum world.time gap between AI-driven claw swings (mobs and obstacles alike) - the AI calls zombie_claws' attack()/a structure's attack_zombie() directly, bypassing click.dm's do_click() dispatch entirely, so nothing else paces it; without this the engaged heartbeat (ZOMBIE_AI_DEFAULT_HEARTBEAT, as low as sleep() grants) would otherwise let it re-attack every single tick. Matches zombie_claws' own attack_speed (black_goo.dm doesn't override the /obj/item default) so an AI zombie's swing cadence feels the same as a player's.

#define
ZOMBIE_AI_OBSTACLE_COMMIT_DURATION

How long an AI zombie stays committed to a chosen blocking obstacle (see get_blocking_obstacle()) before it's allowed to re-pick a different one - mirrors AI_XENO_OBSTACLE_COMMIT_DURATION, prevents flip-flopping between two equally-valid candidate obstacles every tick.

#define
ZOMBIE_AI_PATHFIND_MAX_CELLS

Cell budget (width*height) for the bounded local solver (compute_path()) - same value as XENO_PATHFIND_MAX_CELLS, reused as a plain constant since it describes the native solver's own practical limit, not anything xeno-specific.

#define
ZOMBIE_AI_PATHFIND_MAX_MARGIN

Largest margin compute_path() will grow to even if the cell budget would allow more.

#define
ZOMBIE_AI_PATHFIND_MIN_MARGIN

Smallest search margin around the direct pilot-goal bounding box compute_path() starts from.

#define
ZOMBIE_AI_PATH_GOAL_REPLAN_TOLERANCE

A route target that drifted this many tiles from path_goal still counts as "the same goal" - see advance_along_path().

#define
ZOMBIE_AI_PATH_REPLAN_MIN_INTERVAL

Minimum gap between full replans against a goal that's still drifting within tolerance.

#define
ZOMBIE_AI_PATH_RETRY_COOLDOWN

How long a failed path attempt against the same goal is left alone before trying again.
