code/modules/admin/view_variables/view_variables_session.dm

/datum/view_variables_sessionOne instance per (admin, target) VV window. /client can't host tgui directly, so /client/proc/debug_variables() creates/reuses one of these and opens tgui on it instead of building a browse() HTML page. Sessions are cached per-client so that vv_do_topic()'s internal "datumrefresh" self-call (fired after almost every edit) updates the same window instead of spawning a new one each time.
