code/modules/admin/view_variables/debug_variables.dm

/proc/debug_variableGet displayed variable in VV variable list, as structured data for the tgui ViewVariables interface — each row carries its edit/change/mass-edit/remove hrefs as plain data fields (bare href strings via VV_HREF_TARGET_1V_INTERNAL(), NOT the VV_HREF_TARGET_1V() macro — that one wraps its output in a full "text" tag meant for embedding in real HTML, which is wrong here: storing that whole tag as a data field's value means the row's onClick handler would send the literal string "E" as the href, and client.Topic() can't parse that as a query string) rather than as clickable HTML, since a tgui window can't resolve byond:// links the way a browse() popup window could. See view_variables_session.dm's "click_href" ui_act for how these get fired. If D is a list, name will be index, and value will be assoc value.
