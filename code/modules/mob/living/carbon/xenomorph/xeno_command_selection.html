/datum/xeno_command_selectionShared selection state for the RTS-style hive command console (xeno_command_console.dm). One instance per commander - a Hive Leader's own console, or an admin's console for a picked hive. All three selection input methods (in-world shift-click, roster panel checkboxes, marquee drag-box) write through this single datum, and the console's right-click order issuance reads from it - there is exactly one source of truth for "who is currently selected," regardless of how they got selected.
