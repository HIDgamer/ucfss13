/datum/species/zombie/bursterThe Burster - a zombie variant that ruptures into an infectious cloud of aerosolized black goo on death instead of rising again on the usual timer. Anyone breathing the cloud in gets exposed to the same black_goo disease a bite would give - CBRN filtration and a sealed mask+internals setup both block it, same as any other airborne hazard (see /mob/living/carbon/human/proc/is_gas_infection_protected() below).
/obj/effect/particle_effect/smoke/blackgooThe Burster's infectious cloud. A plain /particle_effect/smoke subtype (not /smoke/chem) since this doesn't use the reagent-carrying machinery at all - just a direct contract_disease() call per affected mob, gated on the same "is this mob currently breathing filtered/sealed air" check breathe() itself uses (handle_breath.dm), not the reagent system's own (unrelated, unguarded) reaction_mob() path.
