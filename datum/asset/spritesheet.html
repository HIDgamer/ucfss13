Only sheets built entirely from on-disk DMI files + a fixed transform pipeline (crop/ scale/color-blend/icon-overlay) can use this - anything built from a dynamically-composited icon (getFlatIcon(), rendered worn-item layers, etc.) has no on-disk file path to hand iconforge and must stay on the native path (e.g. /datum/asset/spritesheet/vending_products).
