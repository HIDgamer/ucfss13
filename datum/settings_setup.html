Settings &amp; Special
/datum/settings_setup

tgui replacement for the legacy MENU_SETTINGS/MENU_SPECIAL panels (code/modules/client/preferences.dm:593-691). MENU_SETTINGS is almost entirely uniform bitflag toggles across 4 different bitfield vars (toggle_prefs/toggles_chat/toggles_sound/ toggles_langchat) — the frontend only ever sends a named field ("ooc_flag", "ert_leader", etc, never a raw bit value), and toggle_bitflag() below resolves that name to the right var + bit internally via .vars[] dynamic access, so the tgui layer never needs to know any DM #define values. The handful of proc-call buttons (set_eye_blur_type() etc, already tgui_alert()-based) are called directly as plain proc calls, same as the legacy "action=proccall" hrefs did. MENU_SPECIAL (ERT toggles) uses the same named-action/toggle_bitflag() pattern against toggles_ert.
